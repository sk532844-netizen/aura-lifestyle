Firebase এখনো কানেক্ট হয়নি

অ্যাডমিন প্যানেল চালাতে Firebase কানেক্ট করতে হবে। ধাপগুলো ADMIN_SETUP.md ফাইলে আছে:

  1. Firebase Console-এ প্রজেক্ট বানান
  2. Email/Password লগইন চালু করে admin user বানান
  3. Firestore তৈরি করুন (asia-south1)
  4. firebase.js-এ config + firestore.rules-এ UID বসান

অ্যাডমিন user Firebase Console → Authentication-এ বানাতে হয়। এই পেজে কোনো পাসওয়ার্ড সেভ করা নেই।
